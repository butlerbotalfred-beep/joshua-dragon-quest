# Test archive

`prototype/` holds the page, the stylesheet and `game.js` of the prototype as they stood after Stage 1 (with the five bug fixes). The new game replaced them in Stage 2. They are kept as a record and are not part of the game. They no longer run from this folder, because their file paths pointed at the top of the repository.

`baseline-prototype.js` is the script that measured the prototype for milestone 0.3.

`prototype/01-smoke.test.js` and `prototype/10-stage1-fixes.test.js` are the Stage 0 and Stage 1 checks as they were written for the prototype. The same checks, rewritten for the new game, are `tests/01-smoke.test.js` and `tests/10-stage1-fixes.test.js`.
