## How to record the family voices (for Stage 7.2)

- Record **one clean 30–60 second sample** per family member (**Joshua**, **Daniel**, **Vanessa**, **Michael**) in a quiet room (WAV or MP3) so Fish Audio can clone each voice and regenerate their lines, **or** record any individual lines below using the exact file names listed.
- Non-family roles (**Keeper**, **Renee**, **Great Black Dragon**, **Narrator**) already use their locked Fish Audio voices.
