# Music

All music was made with Suno for this game and is the same for every build. Use these tracks as they are. Do not make, replace or re-encode music.

| File | Where it plays | Loops |
|---|---|---|
| `main_theme.mp3` | Title screen and menus | Yes |
| `prologue_festival_morning.mp3` | Prologue, before the dragon arrives | Yes |
| `level1_great_woods.mp3` | Level 1, The Great Woods | Yes |
| `level2_treetop_canopy.mp3` | Level 2, Treetop Canopy | Yes |
| `level3_scorched_caverns.mp3` | Level 3, Scorched Caverns | Yes |
| `level4_frostpeak_ridge.mp3` | Level 4, Frostpeak Ridge | Yes |
| `level5_craglands.mp3` | Level 5, The Craglands | Yes |
| `level6_beneath_the_castle.mp3` | Level 6, beneath the castle | Yes |
| `guardian_encounter.mp3` | Every guardian encounter | Yes |
| `hatching.mp3` | Each egg hatching scene | No, play once |
| `ending_festival.mp3` | The festival ending | Yes |

The tracks total about 24 MB. Load only the track for the current place, and stream it rather than loading everything up front, so the first load stays inside its size target. Cross-fade when the track changes so loop points are not heard.
